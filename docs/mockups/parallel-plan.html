Merge cadence. Каждый workstream ребейзится на main ежедневно и мержит PR каждые 1–3 дня. «Слить потом» — это регулярный merge, а не один большой в конце.
Contract-first. Изменения packages/shared — отдельный PR с меткой contract. После merge все worktrees ребейзятся в тот же день.
Изоляция. Каждый dev worktree запускается с NEST_PROFILE: своя SQLite, userData, worktree-root и порт. Иначе инстансы подерутся.
Serialized hotspots. Миграции БД — по одной; pnpm-lock.yaml — один dependency captain; rpc.ts, ipc.ts, app.tsx — owner review.
